# Suspension Statics Lab 懸吊靜力分析

在固定的原始硬點幾何上求解懸吊桿件的拉力與壓力。桿件的截面與材料會用於計算軸向應力、應變及伸縮量。

## 操作方式

1. 在 Windows 雙擊 `Start-SuspensionStaticsLab.bat`。啟動時會顯示四輪範例和靜態負載的應力色階。從車輛工具根目錄也可執行 `python -m SuspensionStaticsLab`。需要 Python 3.10+、Tkinter 及 `requirements.txt` 內的 NumPy。
2. 按「匯入硬點 CSV」載入座標。按「編輯硬點 XYZ」可逐列修改 mm 座標，並可另存為 CSV。編輯後按「套用並關閉」更新幾何；若要依新座標重算範例輪荷，請重新套用加速度。
3. 在「外載工況」設定摩擦圓並套用加速度，或選擇「硬點 XYZ 外力」並新增一組 `Fx, Fy, Fz`（N）。多列外載會相加。可選取一列再更新或刪除。「桿端 A 力矩」和「桿端 B 力矩」接受 `Mx, My, Mz`（N·m），以右手定則把外部力偶施加在所選桿端所連的剛體上。介面會顯示端點與剛體名稱。力偶由該剛體相連的桿件軸力及支承反力平衡；單支二力桿只能沿桿軸傳力。
4. 按「求解桿件受力」。結果依應力絕對值排序，表內保留拉壓符號。左側可拖曳旋轉平移、用滾輪縮放，或切換正交視角。輪胎以透視線框示意；實線為求軸力的桿件，虛線為剛體幾何。
5. 在「桿件截面」的下方表格選取桿件。按住 Ctrl 點選可複選個別桿件，按住 Shift 點選可選取連續範圍。設定外徑、內徑（mm）及楊氏模數（GPa）後，按「套用至選取桿件」更新所有選取的桿件，或按「套用至全部」更新全車。截面圖和截面性質隨內外徑輸入更新。預設為外徑 19 mm、內徑 15 mm、E = 205 GPa 的示例圓管。內徑為 0 可定義實心圓桿。已有軸力結果時，套用截面後會更新應力、應變、伸縮量和色階。

外載的 XYZ 輸入框旁會即時顯示合力或合力矩的大小。套用後，重心、各輪接地點和其他外載列的大小顯示在「合量」欄，單位依該列型態。表格上方會把已套用的力按 XYZ 分量相加並顯示總合力大小，純力矩只影響力矩平衡。

勾選 3D 視圖的「外力分量」可查看各硬點已套用的外力方向。箭頭從硬點出發，標示 `+X`、`−Y` 等帶符號的方向。同一硬點的多筆外力會先按分量相加，零分量省略。箭頭只表示方向，數值可對照載荷表。使用斜視可同時查看三軸方向。

## JSON 專案

按「儲存專案」將目前硬點座標、匯入桿件的端點安裝位置、自訂拓撲、外載表、重心加速與額外下壓力設定、上升時間及每支桿件的外徑、內徑和楊氏模數存入同一個 JSON。輸入截面或外載後，先套用到桿件或載荷表再儲存。首次儲存需選擇路徑，之後可用「儲存專案」更新原檔，或用「另存專案」建立另一份。

以「開啟專案」重新載入 JSON 即可還原設定，並可直接用已儲存的外載求解。輪胎摩擦係數儲存在 `case_settings.tire_mu`。較早的專案若缺少這個欄位，開啟時採預設值 1。舊專案中的「靜態負載」和「空力下壓」開啟後預設為三軸加速度 0，載荷表會還原已儲存的外載。需要比較圈速歷程時，請另外保留並匯入圈速 CSV。

「開啟專案」也可直接匯入 JacobianKinematicsLab 的第 1 版專案 JSON，例如 `LP03_rockerset_project.json`。工具會讀取公尺座標、推桿安裝位置，以及 `deformable_members` 的兩端座標和安裝位置，並將這些元件納入軸力平衡。LP03 的這份 JSON 會載入兩支跨接前搖臂的阻尼器。開啟後採用靜力工具的預設截面，請套用加速度或輸入外載後求解。第一次儲存時會請你選擇新路徑來建立靜力專案。

## 硬點 CSV

UTF-8 CSV 使用 `name,x_m,y_m,z_m` 或 `name,x_mm,y_mm,z_mm`。也接受 `point` 欄和選填 `corner` 欄，例如 `FL,UBJ`。+X 朝前、+Y 朝左、+Z 朝上。四個輪位以 `FL_`、`FR_`、`RL_`、`RR_` 開頭；單輪資料可省略前綴。

| 硬點 | 用途 |
| --- | --- |
| `UCA_F`、`UCA_R`、`LCA_F`、`LCA_R` | 車身固定的上下 A 臂前後內端。亦接受 `UFI`、`URI`、`LFI`、`LRI`。 |
| `UBJ`、`LBJ` | 羊角的上下球接點。一般 A 臂由兩支共用外端的軸力桿表示。 |
| `RACK`、`TOE` | 轉向拉桿的車身固定端和羊角端。亦接受 `ROD_IN`、`ROD_OUT`。 |
| `WC`、`CONTACT`、`FORWARD` | 羊角所帶的輪心、接地點與選填輪向。缺接地點時會建立輪心下方的示意接地點，可在介面編輯。`WHEEL_CENTER` 亦可作為輪心。 |
| `PUSH_IN`、`PUSH_OUT_UPRIGHT` | 推桿接羊角的配置。外端也可用 `PUSH_OUT`（下 A 臂）或 `PUSH_OUT_UCA`（上 A 臂）。推桿接 A 臂時，該 A 臂與車身的連接按剛體及鉸鏈建模，並由球接點將力傳給羊角。該臂的兩條虛線為剛體外形。 |
| `ROCKER_A`、`ROCKER_B`、`DAMPER_IN`、`DAMPER_BODY` | 齊備時，使用可繞軸轉動的剛性搖臂和軸向阻尼器。`DAMPER_IN` 在搖臂上，`DAMPER_BODY` 固定在車身。資料不全時，推桿內端固定於車身。 |
| `CG` | 全車重心。未提供時會依車輪位置補上，可在硬點編輯器內調整。 |
| `COP` | 選填的車身外力作用點。匯入座標後可在「硬點 XYZ 外力」選用。 |

啟動時與按下「四輪範例幾何」時，都讀取此工具內附的[預設硬點 CSV](examples/default_hardpoints.csv)。這份 CSV 複製自 JacobianKinematicsLab 的預設幾何，可隨 SuspensionStaticsLab 資料夾一同搬移。目前範例將推桿外端接至上 A 臂。靜力模型將推桿內端固定於車身，每輪求解四支軸力桿。含 `DAMPER_IN` 和 `DAMPER_BODY` 硬點的[範例 CSV](examples/hardpoints.csv)可手動匯入。

匯入 JacobianKinematicsLab 專案 CSV 時，也會讀取 `jacobian_project` 欄內 `deformable_members` 的端點座標（m）與安裝位置。元件以原名稱加入軸力桿件，兩端以 `<名稱>_A`、`<名稱>_B` 顯示並可編輯。端點可各自接到車身或某個輪位的搖臂。接搖臂時，該輪位需提供搖臂軸點和完整的推桿連接。編輯後另存硬點 CSV 會保留這些桿件及安裝位置。

例如 `LP03_rockerset.csv` 的 `DAMPER_1` 連接右前與左前搖臂，兩側共用同一個軸力未知數。若左右兩側在某個工況下要求的共同桿件軸力不同，求解會回報外載無法平衡。匯入元件的模型採固定幾何與二力桿假設，求解時沿用其他軸力桿件的截面及材料設定方式。

只有幾何定位點的 CSV 仍可預覽。求解輪荷時，需提供完整受力路徑及車身支承。

## 摩擦圓工況

在「外載工況」直接拖曳摩擦圓上的點，或輸入縱向 `ax`、側向 `ay` 與垂直 `az`（m/s²）。圖中橫軸為 `ay`，縱軸為 `ax`。按「套用加速度」會更新載荷表並求解。若原工況會使輪胎離地，工具會沿同一方向縮小 `ax`、`ay`，在狀態欄顯示原始及採用值。`az`、質量、摩擦係數和下壓力在搜尋時維持固定。

按「掃描可行區」會評估原點，以及 120 個方向各 24 個半徑的取樣點，並在輪胎接地狀態變化的地方加密。結果依各桿件取樣所得的最大軸力絕對值排序，保留拉壓正負號及對應的加速度。「套用峰值工況」會載入全車峰值對應的加速度並求解。

預設質量 321 kg、三軸加速度為 0、輪胎摩擦係數 `μ = 1`，並計入重力。保留這些加速度與重力設定、關閉額外下壓力，即可求純車重的靜態負載。額外下壓力 `D` 沿 −Z 作用於重心。四輪正向力合計 `W = m(g + az) + D`，取消「計入重力」時 `g` 採 0。

水平加速度上限為 `A = μ × W / m`，可選範圍為 `ax² + ay² ≤ A²`。圖形依視窗比例呈橢圓，換算成加速度座標為圓形。若 `A = 0`，可選原點。

`W > 0` 時，以 `rx = m × ax / W`、`ry = m × ay / W` 計算各輪的 `Fx_i = rx × Fz_i` 與 `Fy_i = ry × Fz_i`。四輪縱向與側向合力分別為 `m × ax` 與 `m × ay`，每輪合成抓地力均限制在 `μ × Fz_i` 以內。

基準分配比例 `s_i` 從各軸左右等分的初值做最小幅度修正，滿足 `Σs_i = 1`、`Σ(y_i × s_i) = 0`、`Σ(x_i × s_i) = 0`。再從 `s_i × W` 做最小幅度修正求正向力。矩陣三列為 `1`、`y_i − ry × z_i`、`rx × z_i − x_i`，右側依序為 `W`、`0`、`0`。接地點座標以重心為基準。圖中的範圍代表抓地上限，工具也會檢查負輪荷與桿件平衡。手動輸入的接地力與圈速 CSV 內的實測力直接用於求解。

## 受力歷程

- **加速度上升**。在「外載工況」設定目標三軸加速度、質量、輪胎摩擦係數、重力及額外下壓力。切至「受力歷程」，設定上升時間（秒），按「產生加速歷程」。三軸加速度由 0 線性升到輸入值，共 101 筆。各時間點使用同一硬點幾何、摩擦圓分配、摩擦係數、重力設定和啟用的下壓力。上升時間改變加速速率與圖的時間尺度。
- **圈速 CSV**。在「受力歷程」按「匯入圈速 CSV」。CSV 需有嚴格遞增的 `time_s` 及至少兩筆資料。若提供完整的 `fx_FL_N,fy_FL_N,fz_FL_N` 及 `FR`、`RL`、`RR` 對應欄位，直接在各輪接地點施加這些力，單位為 N。若只有車身加速度，可使用 `ax_m_s2,ay_m_s2,az_m_s2`、對應的 `_g` 欄位或 `long_g,lat_g`，缺少 `az` 時採零。加速度換算輪荷時會使用摩擦圓分配、質量、輪胎摩擦係數、重力設定及啟用的下壓力。
- **同步比較**。上圖顯示車身座標的 `ax`、`ay`、`az`（m/s²），下圖顯示桿件軸力（N）。播放、拖曳滑桿或點選任一圖，兩圖及 3D 視圖會同步更新。加速度採輸入或 CSV 原值，重力另外計入載荷。使用四輪力求解時，CSV 缺少的加速度分量留白。
- **當下最大軸力**。下方讀值依 `|軸力|` 找出目前受力最大的桿件並顯示帶符號的力值。勾選「追蹤當下最大軸力」可顯示各時刻的最大值曲線，並在 3D 視圖追蹤該桿件。色階上限為整段歷程的最大絕對應力。
- **單支桿件統計**。在下拉選單或 3D 視圖選桿，會顯示該桿的峰值、峰值時間、平均絕對軸力與帶符號平均。峰值取絕對值最大那一筆並保留拉壓符號。平均依取樣間隔加權，假設樣本間線性變化。匯入完整單圈 CSV 時，統計範圍即整圈。

## 圓形截面性質

截面圖依直徑比例顯示。下表的 `Dₒ` 為外徑，`Dᵢ` 為內徑，`c = Dₒ/2` 為最外緣距離。`I` 與 `S` 適用於任何通過圓心的直徑軸，極截面性質以圓心為準。

| 性質 | 公式 | 單位 |
| --- | --- | --- |
| 截面積 A | `π(Dₒ² − Dᵢ²)/4` | mm² |
| 截面二次矩 I | `π(Dₒ⁴ − Dᵢ⁴)/64` | mm⁴ |
| 截面係數 S | `I/c` | mm³ |
| 截面迴轉半徑 r | `√(I/A)` | mm |
| 極慣性矩 J | `2I` | mm⁴ |
| 極截面係數 Zₚ | `J/c` | mm³ |
| 極迴轉半徑 rₚ | `√(J/A)` | mm |

軸力平衡使用硬點幾何。軸向應力、應變和伸縮量使用截面積與楊氏模數，其餘截面性質供查閱。

## 桿件干涉

靜力與受力歷程求解會在原始硬點姿態檢查軸力桿件。每支桿以兩端之間的中心線段為軸，採用半徑等於外徑一半的膠囊體近似其外形。用兩桿的半徑和減去中心線段的三維最短距離，所得正值為估計重疊量。警告會列出桿件名稱及估計重疊量（mm），恰好接觸時不發出警告。

兩桿共用端點時，各自從該端排除兩倍半徑和的長度，再檢查其餘部分。中心線完全重合的桿件仍會列入檢查。警告不影響平衡結果。剛體、實際接頭外形與懸吊行程內的干涉需另外檢查。

## 自訂拓撲

任意點名可搭配拓撲 JSON。先匯入 CSV，再按「載入拓撲 JSON」。`fixed` 裡的硬點固定於車身，`bodies` 把一組硬點歸到共同的剛體。沒有指派到車身或剛體的桿端視為只傳三軸力的鉸接節點。各支 `rods` 需有唯一名稱與兩個 CSV 端點。以下為原點鉸接節點加三支正交桿的例子，對 `joint` 加力可驗證拉壓方向。

```json
{
  "fixed": ["anchor_x", "anchor_y", "anchor_z"],
  "bodies": {},
  "rods": [
    {"name": "X", "a": "joint", "b": "anchor_x"},
    {"name": "Y", "a": "joint", "b": "anchor_y"},
    {"name": "Z", "a": "joint", "b": "anchor_z"}
  ]
}
```

## 計算定義

- 對每個剛體求 `ΣF = 0` 與 `ΣM = 0`，鉸接節點求 `ΣF = 0`。每支桿的未知數 `P` 沿原始端點連線，`P > 0` 為拉力、`P < 0` 為壓力。若平衡式給不出唯一內力，或外載無法平衡，介面會顯示矩陣秩及原因。
- 截面積 `A = π (Dₒ² − Dᵢ²) / 4`，軸向應力 `σ = P/A`，軸向應變 `ε = σ/E`，線彈性伸縮量 `ΔL = PL₀/(AE)`。圖上以當前工況的 `|σ|` 由藍漸紅。變形量採求解前的原始桿長，並保留伸長或縮短的符號。
- 這是固定幾何的軸力平衡與線彈性後處理。應變及伸縮量僅供讀值，幾何始終顯示原始座標。壓桿挫屈及 A 臂彎曲需額外做結構分析。
